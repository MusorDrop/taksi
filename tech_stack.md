# Стек технологий проекта «Попутка ИИ»


## Frontend (Клиентская часть)
- **Фреймворк:** React 19.
- **Сборщик:** Vite 6.
- **Язык:** TypeScript 5 (строгая типизация).
- **Компонентная библиотека:** Material UI (MUI v6) + Emotion.
- **Платформа:** Progressive Web App (PWA) с адаптацией под экраны смартфонов и настольные браузеры.
- **Картография:** Leaflet + `react-leaflet` (интерактивная карта и гео-метки).

## Backend (Серверная часть)
- **Среда выполнения:** Node.js (v20+).
- **Фреймворк:** Express.js v5.
- **База данных:** PostgreSQL 15+ с расширением PostGIS для гео-пространственных расчетов (`ST_DWithin`, `ST_DistanceSphere`).
- **Аутентификация & безопасность:** JWT (jsonwebtoken), bcryptjs, Helmet, Express Rate Limit, CORS.
- **Работа с файлами:** Multer с проверкой magic bytes сигнатур для загрузки аватарок.
- **Драйвер БД:** `pg` (node-postgres) с пулом соединений и строгими транзакциями (`FOR UPDATE`).

## База данных и гео-обработка
- **СУБД:** PostgreSQL 15+.
- **Расширение:** PostGIS (типы `geometry(Point, 4326)` и геодезический `geography`, индексы GiST).
- **Экономическая модель:** Базовый тариф 6 руб/км с коэффициентом x1.3 в часы пик и фиксированной ставкой за посадочное место.

## Искусственный Интеллект (AI / LLM)
- **Интеграция:** Модульный коннектор в Node.js для распознавания текстовых запросов естественного языка в структурированные параметры маршрута (Gemini, OpenAI, YandexGPT).

## Внешние сервисы и картография
- **Картография:** OpenStreetMap / Leaflet (отображение интерактивной карты, точек посадки и высадки, радиусов гео-поиска). Будет работать в связке с локальной базой PostGIS.
