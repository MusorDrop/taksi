# Попутка ИИ (Студенческий райдшеринг)

## О проекте
Платформа для совместных поездок студентов (райдшеринг). Позволяет студентам с автомобилями публиковать свои регулярные маршруты, а пассажирам — находить попутчиков. Система автоматически подбирает оптимальные совпадения по времени, маршруту и рейтингу, а также рассчитывает справедливую стоимость поездки. Проект включает в себя AI-интеграцию для «умного матчинга» пассажиров и водителей с гибкими окнами по времени.

## Стек технологий
- **Frontend:** HTML5, CSS3, JavaScript (Vanilla JS). Формат PWA.
- **Backend:** Node.js + Express.js.
- **База данных:** PostgreSQL + PostGIS (для гео-запросов и координатных расчетов).
- **ИИ (AI):** LLM API (модель будет выбрана позже) для парсинга запросов пользователей.

## Как начать работу

### 1. Что нужно установить (Инструкция)
Для разработки и локального запуска проекта на вашем компьютере (Windows) должны быть установлены следующие программы:

- **Node.js** (версия 20+): Для работы бэкенда и пакетного менеджера `npm`.
  - *Как установить:* Перейдите на официальный сайт [nodejs.org](https://nodejs.org/), скачайте установщик версии "LTS" (Long Term Support) и просто прокликайте установку до конца.
- **PostgreSQL**: Сама база данных.
  - *Как установить:* Скачайте установщик с официального сайта [postgresql.org](https://www.postgresql.org/download/windows/). При установке обязательно **запомните пароль** для пользователя `postgres` — он понадобится вашему серверу для подключения.
- **PostGIS**: Специальное гео-расширение для PostgreSQL (для маршрутов).
  - *Как установить:* В самом конце установки PostgreSQL вам предложат запустить утилиту **Stack Builder** (согласитесь). В её меню найдите раздел `Spatial Extensions`, отметьте галочкой `PostGIS` актуальной версии и установите.
- **Git**: Система контроля версий.
  - *Как установить:* Скачайте установщик с [git-scm.com](https://git-scm.com/downloads) и установите со стандартными настройками (нажимая "Next").

### 2. Запуск проекта (Подробная инструкция)
1. Откройте терминал или командную строку. На Windows это можно сделать, нажав `Win + R`, напечатав `cmd` и нажав `Enter`. Либо просто откройте встроенный терминал в вашей среде разработки (например, в VS Code: меню `Terminal -> New Terminal`).
2. Убедитесь, что вы находитесь в папке проекта `taksi` (команда `cd путь\к\папке\taksi`).
3. Установите зависимости (если вы этого еще не сделали). Введите в консоль:
   ```cmd
   npm install
   ```
   *Дождитесь окончания загрузки (появится папка `node_modules`).*
4. Запустите бэкенд-сервер командой:
   ```cmd
   node index.js
   ```
5. Сервер работает! Откройте браузер и перейдите по адресу: `http://localhost:3000`
### 3. Где работать (Среда разработки)
Вы можете использовать любой удобный редактор кода, но мы рекомендуем:
- **Visual Studio Code (VS Code)** — абсолютный лидер. Бесплатный, быстрый, с огромным количеством плагинов для JS и базы данных.
- **WebStorm** — профессиональная платная IDE от JetBrains (отлично подходит для JS и Node.js).
- **Google Antigravity IDE** — если разработка ведется преимущественно в паре с AI-агентами.
