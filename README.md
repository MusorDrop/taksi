# Попутка ИИ (Студенческий райдшеринг)

## О проекте
Платформа для совместных поездок студентов (райдшеринг). Позволяет студентам с автомобилями публиковать свои регулярные маршруты, а пассажирам — находить попутчиков. Проект использует ИИ для «умного матчинга» с гибкими окнами по времени.

---

## Архитектура проекта (Монорепозиторий)
Проект разделен на две независимые части (папки), каждая из которых имеет свой собственный `README.md` с техническими деталями:

### 1. [`/frontend`](./frontend/README.md) — Клиентская часть (Интерфейс пользователя)
- **Стек:** React, TypeScript, Vite, HTML, CSS.
- **Особенности:** Строгая типизация (TS), ESLint-проверки, адаптивный дизайн (Mobile-first), подготовка под PWA.
- **Структура:** Основной код находится в папке `src`, статика — в `public`.

### 2. [`/backend`](./backend/README.md) — Серверная часть (API)
- **Стек:** Node.js, Express.js.
- **База данных:** PostgreSQL + PostGIS (для гео-запросов и координатных расчетов).
- **ИИ (AI):** Интеграция LLM по API для умного матчинга.
- **Конфигурация:** В будущем здесь появится файл `.env` для безопасного подключения к базе данных.

## Как начать работу локально

### Шаг 1. Базовое ПО (Один раз)
- **Node.js** (версия 20+): [nodejs.org](https://nodejs.org/).
- **PostgreSQL**: [postgresql.org](https://www.postgresql.org/download/windows/). При установке **обязательно запомните пароль** (`postgres`).
- **PostGIS**: Устанавливается через *Stack Builder* в конце установки PostgreSQL.

### Шаг 2. Запуск БЭКЕНДА (Сервер)
1. Откройте терминал в папке проекта.
2. Перейдите в папку бэкенда:
   ```cmd
   cd backend
   ```
3. Установите зависимости:
   ```cmd
   npm install
   ```
4. Запустите сервер (будет работать на порту `3000`):
   ```cmd
   node index.js
   ```

### Шаг 3. Запуск ФРОНТЕНДА (Клиент)
1. Откройте **новый** терминал (оставьте бэкенд работать в старом).
2. Перейдите в папку фронтенда:
   ```cmd
   cd frontend
   ```
3. Установите зависимости:
   ```cmd
   npm install
   ```
4. Запустите клиент:
   ```cmd
   npm run dev
   ```
   *Терминал покажет ссылку (обычно `http://localhost:5173`), по которой доступен сайт.*

## Правила работы с Git (Для команды)
1. **`main`** — ветка только для стабильного, протестированного кода (продакшен). Сюда заливаем только из `dev`.
2. **`dev`** — **основная рабочая ветка для объединения кода!** Все Pull Request'ы от разработчиков должны идти сюда.
3. Ваша личная ветка (например, `feat/backend` или `frontend`) — ветка для разработки фичи. 

**Процесс:** Пишете код в своей ветке -> Делаете Pull Request в `dev` -> Тестируем вместе -> Заливаем в `main`.
