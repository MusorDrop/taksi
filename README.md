# Попутка ИИ (Студенческий райдшеринг)

## О проекте
Платформа для совместных поездок студентов (райдшеринг). Позволяет студентам с автомобилями публиковать свои регулярные маршруты, а пассажирам — находить попутчиков. Проект использует ИИ для «умного матчинга» с гибкими окнами по времени.

---

## Архитектура и структура проекта (Монорепозиторий)
Проект разделен на две независимые части, чтобы избежать конфликтов при разработке:
- **`/backend`** — серверная часть (Node.js, Express, PostgreSQL, API ИИ).
- **`/frontend`** — клиентская часть (UI, PWA).

---

## Правила работы с Git (Важно для команды!)
Мы используем ветку `dev` для тестирования и интеграции кода:
1. **`main`** — ветка только для стабильного, протестированного кода (продакшен). Сюда заливаем только из `dev`.
2. **`dev`** — **основная рабочая ветка для объединения кода!** Все Pull Request'ы от разработчиков должны идти сюда.
3. Ваша личная ветка (например, `alfa-0.0.1` или `frontend`) — ветка для разработки фичи. 

**Процесс:** Пишете код в своей ветке -> Закидываете (Pull Request) в `dev` -> Тестируем вместе -> Заливаем в `main`.

---

## Стек технологий
- **Frontend:** HTML5, CSS3, JavaScript (Vite/React/Vanilla).
- **Backend:** Node.js + Express.js.
- **База данных:** PostgreSQL + PostGIS.

---

## Как начать работу

### 1. Установка ПО (Один раз)
- **Node.js** (версия 20+). Скачать: [nodejs.org](https://nodejs.org/).
- **PostgreSQL**. Скачать: [postgresql.org](https://www.postgresql.org/download/windows/). Обязательно **запомните пароль** суперпользователя `postgres`.
- **PostGIS**. Устанавливается через галочку *Stack Builder* в конце установки PostgreSQL (раздел Spatial Extensions).

### 2. Запуск БЭКЕНДА (Сервер)
1. Откройте терминал в папке проекта.
2. Перейдите в папку бэкенда:
   ```cmd
   cd backend
   ```
3. Установите зависимости:
   ```cmd
   npm install
   ```
4. Запустите сервер:
   ```cmd
   node index.js
   ```
   *Сервер будет доступен по адресу: `http://localhost:3000`*

### 3. Запуск ФРОНТЕНДА (Клиент)
1. Откройте **новый** терминал (оставив работать бэкенд в старом).
2. Перейдите в папку фронтенда:
   ```cmd
   cd frontend
   ```
3. Установите зависимости:
   ```cmd
   npm install
   ```
4. Запустите клиент:
   ```cmd
   npm run dev
   ```
   *Терминал покажет ссылку (обычно `http://localhost:5173`), по которой доступен сайт.*
