# Стек технологий проекта «Попутка ИИ»

## Frontend (Клиентская часть)
- **Языки:** HTML, CSS, JavaScript (Vanilla JS).
- **Платформа:** Progressive Web App (PWA).
- **Масштабирование:** возможность обернуть веб-сайт в нативные приложения для Android/iOS (через Capacitor/Cordova) в будущем.

## Backend (Серверная часть)
- **Среда выполнения:** Node.js.
- **Фреймворк:** Express.js (Рекомендуется). Писать сервер на «чистом» Node.js без фреймворка нецелесообразно (это долго и сложно). Express.js — это индустриальный стандарт, который легко устанавливается одной командой (`npm install express`) и делает создание бэкенда быстрым и удобным.
- **Особенности:** реализация API для связи клиентской части с базой данных и сервисами искусственного интеллекта.

## База данных
- **СУБД:** PostgreSQL.
- **Специфика:** использование расширения PostGIS для эффективной обработки пространственных данных (координаты, радиусы поиска, сопоставление маршрутов).

## Искусственный Интеллект (AI / LLM)
- **Провайдер:** Предстоит выбрать (например, OpenAI, Anthropic, Gemini, YandexGPT, локальные модели).
- **Интеграция:** через REST API с бэкенда на Node.js.

## Внешние сервисы и картография
- **API Яндекс.Карт:** используется для работы с реальной дорожной ситуацией (отображение интерактивной карты в приложении, геокодирование адресов, получение времени в пути с учетом текущих пробок). Будет работать в связке с нашей локальной базой PostGIS.
