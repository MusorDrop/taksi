# Попутка ИИ — Frontend (Клиентская часть)

Здесь находится интерфейс пользователя (веб-приложение).

## Стек
- **HTML, CSS, JS** (React / Vite)
- Адаптивный дизайн (Mobile-first)

## Запуск для разработки
1. Установите зависимости:
   ```cmd
   npm install
   ```
2. Запустите сервер разработки:
   ```cmd
   npm run dev
   ```

## Структура
Здесь должны лежать файлы `package.json`, папки `src` и `public`.
