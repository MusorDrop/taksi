# Попутка ИИ — Frontend (Клиентская часть)

Современное адаптивное PWA/SPA веб-приложение для студентов УрФУ, оптимизированное под мобильные экраны и десктоп. Реализовано на **React 19 + TypeScript + Vite + Material UI (MUI v6)**.

---

## 📱 Основные экраны и пользовательские сценарии

### 1. 🔍 Поиск поездок (`FindRidesScreen`)
- Поиск поездок с поддержкой фильтрации по точкам посадки/высадки, радиусу и времени.
- Картографический интерактивный компонент (`RouteMap`) на базе Leaflet/OpenStreetMap с отображением точек маршрута.
- Карточки поездок (`RideCard`):
  - Информация о водителе (аватар, имя, рейтинг, ссылка на Telegram).
  - Кнопка **«Позвонить»** (прямой вызов через `tel:...`) для оперативной связи с водителем.
  - Метка типа поездки: Одноразовая (по дате) или Регулярная (с днями недели).
  - Прозрачная **фиксированная цена за 1 место** (без скрытых пересчетов Split Fare).
  - Атомарное бронирование 1 места (`Присоединиться`).

### 2. 🚗 Создание поездки (`OfferRideScreen`)
- **Блокировка без авто:** если у водителя нет добавленных автомобилей в гараже, форма создания поездки блокируется, и выводится предупреждение с кнопкой быстрого перехода в профиль.
- **Выбор типа поездки:**
  - 📆 **Одноразовая (`one_off`):** выбор конкретной календарной даты и времени выезда.
  - 🔄 **Регулярная (`regular`):** выбор дней недели (Пн, Вт, Ср, Чт, Пт, Сб, Вс) для постоянных поездок.
- **Интеллектуальная рекомендация цены:** автоматический расчет справедливой цены на основе расстояния и часов пик.
- **Привязка автомобиля:** автоматическое определение вместимости на основе количества мест (`seats`) выбранного авто.

### 3. 🧳 Мои поездки (`MyTripsScreen`)
- Вкладки **«Я пассажир»** и **«Я водитель»**.
- **Возможности водителя:**
  - Просмотр списка подтвержденных пассажиров с их именами, аватарками, телефонами и Telegram-контактами.
  - **Исключение пассажира:** возможность кикнуть попутчика с мгновенным возвратом свободного места в поездку.
  - **Редактирование маршрута:** модальное окно изменения адресов, времени, цены за место и количества мест.
- **Возможности пассажира:**
  - Просмотр статуса поездки и контактов водителя.
  - Отмена участия в поездке с автоматическим освобождением места.
  - Оставление отзыва и оценки (1–5 звезд) после завершения поездки.

### 4. 👤 Личный профиль (`ProfileScreen`)
- **Контакты:**
  - Просмотр подтвержденного номера телефона и Telegram-username.
  - Модальное окно редактирования телефона и Telegram (`PATCH /api/auth/me`).
- **Аватарка:** загрузка и обновление фото профиля с предварительной валидацией на клиенте.
- **Гараж автомобилей:**
  - Список автомобилей с отображением марки, цвета, госномера и **количества мест**.
  - Форма добавления автомобиля с указанием числа мест (`seats`, 1–8).
  - Модальное окно **редактирования автомобиля** (изменение марки, цвета, номера, мест).
- **Настройки интерфейса:** переключение между светлой и темной темами оформления (MUI).

### 5. 🛡 Админ-панель (`AdminScreen`)
- Скрытый роут доступен по URL `/admin` или хешу `#admin`.
- Просмотр статистики системы (пользователи, активные поездки, отзывы, средний чек).
- Управление аккаунтами пользователей: блокировка и разблокировка нарушителей.

---

## 🛠 Технологический стек Frontend

- **Фреймворк:** React 19
- **Сборщик:** Vite 6
- **Язык:** TypeScript 5 (строгая типизация)
- **Компоненты & UI:** Material UI (MUI v6) + Emotion
- **Иконки:** `@mui/icons-material`
- **Картография:** Leaflet + `react-leaflet`
- **PWA-возможности:** адаптивная верстка под Mobile Viewport, поддержка touch-событий, safe-area-inset

## 🚀 Локальный запуск

```bash
# Установка зависимостей
npm install

# Запуск dev-сервера с hot-reload
npm run dev

# Сборка production бандла
npm run build
```
