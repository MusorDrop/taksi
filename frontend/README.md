# 📱 Клиентская часть платформы «Попутка» (Frontend)

Адаптивное клиентское веб-приложение сервиса совместных поездок для студентов и сотрудников УрФУ (PWA-ready). Поддерживает светлую/темную темы, управление поездками и глубокую интеграцию с Яндекс Картами.

---

## 🛠 Стек технологий

- **Фреймворк:** [React 19](https://react.dev/) + [Vite 8](https://vite.dev/) (HMR, быстрая сборка)
- **Язык:** [TypeScript 5](https://www.typescriptlang.org/) (строгая типизация)
- **UI & Дизайн-система:** [Material UI (MUI v7)](https://mui.com/) + `@emotion/styled` + Material Icons
- **Картография:** [Яндекс Карты API 2.1](https://yandex.ru/dev/maps/jsapi/) (`useRouteMap`, `useAddressSuggest`, `RouteMap`)
- **UX/PWA:** Адаптивность под мобильные экраны (`safe-area-inset`), нижний бар `BottomNav`, динамическая смена тем

---

## 🚀 Быстрый запуск

### 1. Установка и переменные окружения
```bash
cd frontend
npm install
```

Создайте `.env` в папке `frontend/`:
```env
# URL бэкенда
VITE_API_URL=http://localhost:3000

# API-ключ JavaScript API Яндекс Карт 2.1
VITE_YANDEX_MAPS_API_KEY=your_yandex_maps_api_key
```

### 2. Запуск и сборка
```bash
# Режим разработки с HMR (http://localhost:5173):
npm run dev

# Проверка типов TypeScript и сборка продакшен-бандла:
npm run build

# Предпросмотр продакшен-сборки:
npm run preview
```

## 🧭 Ключевые экраны

| Экран | Компонент | Возможности |
|---|---|---|
| 🔍 **Поиск поездок** | `FindRidesScreen` | NLP-поиск на естественном языке, фильтры, карточки `RideCard`, бронь в 1 клик, вызов `tel:` и связь в Telegram |
| 🚗 **Создание поездки** | `OfferRideScreen` | Автокомплит адресов Екатеринбурга, интерактивная карта `RouteMap`, автокалькулятор цены, проверка гаража авто |
| 🧳 **Мои поездки** | `MyTripsScreen` | Вкладки водителя и пассажира, управление участниками, отмена брони, выставление оценок (1–5 звезд) |
| 👤 **Профиль** | `ProfileScreen` | Редактирование контактов, аватар, гараж автомобилей (1–8 мест), светлая/темная тема |
| 🛡 **Админка** | `AdminScreen` | Метрики платформы, список пользователей, блокировка/разблокировка (`/admin`) |

## 🗺 Интеграция с Яндекс Картами (API 2.1)

- **`useAddressSuggest`**: автодополнение адресов и корпусов через `ymaps.suggest` в пределах Екатеринбурга (`[56.60, 60.20]` – `[57.05, 61.05]`) с fallback на бэкенд.
- **`useRouteMap` & `RouteMap`**: инициализация карты, метки посадки/высадки, отрисовка полилиний дорог (`LineString`) и центрирование (`map.setBounds`).

## 📁 Структура исходного кода

```text
frontend/
├── public/                      # Статические файлы, манифест, иконки
├── src/
│   ├── api/                     # Модуль API-запросов к серверу Express
│   ├── components/              # Переиспользуемые UI-компоненты (RouteMap, RideCard, BottomNav...)
│   ├── hooks/                   # Пользовательские хуки (useRouteMap, useAddressSuggest, useRideForm...)
│   ├── screens/                 # Основные экраны приложения (FindRides, OfferRide, MyTrips...)
│   ├── types/                   # Интерфейсы и TypeScript-типы
│   ├── utils/                   # Вспомогательные утилиты (форматирование дат, NLP-парсер, формулы цен)
│   ├── App.tsx                  # Корневой компонент с маршрутизацией и провайдерами
│   ├── AppContext.tsx           # Глобальное состояние (пользователь, поездки, действия)
│   ├── ThemeModeContext.tsx     # Контекст переключения светлой/темной темы
│   ├── theme.ts                 # Определение цветовых палитр и типографики MUI
│   └── main.tsx                 # Точка входа React
├── index.html                   # HTML-шаблон с подключением Яндекс Карт API 2.1
├── vite.config.ts               # Конфигурация сборщика Vite
└── package.json                 # Зависимости и скрипты
```
