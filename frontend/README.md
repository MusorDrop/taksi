# 📱 Клиентская часть платформы «Попутка» (Frontend)

Адаптивное клиентское веб-приложение сервиса совместных поездок (карпулинг) для студентов и сотрудников УрФУ. Интерфейс оптимизирован для мобильных устройств (PWA-ready) и десктопных браузеров, поддерживает темную и светлую темы, а также глубокую интеграцию с гео-сервисами Яндекс Карт.

---

## 🛠 Технологический стек

- **Библиотека пользовательского интерфейса:** [React 19](https://react.dev/)
- **Инструмент сборки:** [Vite 8](https://vite.dev/) (сверхбыстрый Hot Module Replacement / HMR)
- **Язык программирования:** [TypeScript 5](https://www.typescriptlang.org/) (строгая типизация компонентов, хуков и моделей данных)
- **UI-компоненты и стилизация:**
  - [Material UI (MUI)](https://mui.com/) — готовая дизайн-система, компоненты по спецификации Material Design 3
  - `@mui/icons-material` — библиотека векторных иконок Google Material Symbols / Icons
  - `@emotion/react` и `@emotion/styled` — CSS-in-JS движок стилизации компонентов
  - `@fontsource/roboto` и `@fontsource/inter` — типографика проекта
- **Картография и гео-сервисы:**
  - **[Яндекс Карты API 2.1](https://yandex.ru/dev/maps/jsapi/)** (`https://api-maps.yandex.ru/2.1/`)
  - Хук `useRouteMap` и компонент `RouteMap` для визуализации маршрута, полилиний дорог (`LineString`) и интерактивных меток посадки/высадки
  - Хук `useAddressSuggest` для автокомплита адресов через клиентский `ymaps.suggest` в границах Екатеринбурга с fallback на бэкенд `/api/suggest`
- **Адаптивность и мобильный UX:**
  - Поддержка `safe-area-inset` для современных смартфонов с вырезами экрана
  - Нижняя панель навигации `BottomNav` для комфортного управления одной рукой
  - Динамическое переключение светлой и темной темы оформления через `ThemeModeContext`

## 🚀 Быстрый запуск

### 1. Предварительные требования
- Установлен **Node.js 20+** и пакетный менеджер **npm**.
- Запущен сервер бэкенда (по умолчанию на порту `3000`).

### 2. Установка зависимостей
```bash
cd frontend
npm install
```

### 3. Настройка переменных окружения (`.env`)
Создайте файл `.env` (или `.env.local`) в каталоге `frontend/`:

```env
# Адрес бэкенд-сервера API
VITE_API_URL=http://localhost:3000

# Ключ JavaScript API Яндекс Карт 2.1 (получается в Кабинете Разработчика Яндекса)
# Необходим для отображения интерактивной карты и подсказок адресов:
VITE_YANDEX_MAPS_API_KEY=your_yandex_maps_api_key
```

> [!NOTE]
> Скрипт Яндекс Карт подключается в файле [index.html](file:///C:/Users/denis/Documents/antigravity/taksi/taksi/frontend/index.html) с автоматической подстановкой переменной `%VITE_YANDEX_MAPS_API_KEY%`. Даже без указания ключа интерфейс приложения сохраняет работоспособность благодаря резервному поиску адресов через сервер и встроенному словарю ориентиров УрФУ.

### 4. Запуск в режиме разработки (Dev Server)
```bash
npm run dev
```
После запуска откройте в браузере адрес: **`http://localhost:5173`** (или указанный Vite порт). Включена поддержка мгновенного обновления без перезагрузки страницы (HMR).

### 5. Сборка для продакшена (Production Build)
```bash
# Проверка типов TypeScript и сборка оптимизированного бандла
npm run build

# Локальный предварительный просмотр собранного продакшен-бандла
npm run preview
```

## 🧭 Ключевые экраны и пользовательские сценарии

### 1. 🔍 Поиск поездок (`FindRidesScreen`)
- **Умная фильтрация:** фильтры по дню недели (актуально для регулярных маршрутов), направлению и времени отправления.
- **NLP / AI-поиск:** текстовый поиск на естественном языке (например, *"завтра в 8:30 Новокольцовский"*).
- **Карточка поездки (`RideCard`):**
  - Имя водителя, аватар, рейтинг и ссылка на Telegram;
  - Кнопка **«Позвонить»** (прямой вызов `tel:...`) для мгновенной связи;
  - Фиксированная цена за посадочное место;
  - Быстрое бронирование места в один клик.

### 2. 🚗 Создание маршрута водителем (`OfferRideScreen`)
- **Умный автокомплит с геокодингом:** поля ввода точек "Откуда" и "Куда" на базе MUI `Autocomplete` и Yandex Maps Suggest с жесткой привязкой к Екатеринбургу и кампусам УрФУ.
- **Интерактивная карта (`RouteMap`):** отображение точек старта, финиша и полилинии реального маршрута по дорогам.
- **Умный калькулятор цены:** автоматический расчет справедливой стоимости с учетом километража и часов пик (утро: 07:30–09:30, вечер: 17:00–19:00).
- **Форматы поездок:**
  - Одноразовые (`one_off`) — на конкретную дату и время;
  - Регулярные (`regular`) — с выбором дней недели (Пн-Вс).
- **Защита от создания без авто:** если у водителя нет автомобиля в гараже, форма блокируется с предложением перейти в профиль.

### 3. 🧳 Мои поездки (`MyTripsScreen`)
- Разделение на вкладки **«Я пассажир»** и **«Я водитель»**.
- **Инструменты водителя:**
  - Просмотр списка пассажиров с их контактами;
  - Возможность исключить пассажира из поездки (место возвращается автоматически);
  - Быстрое редактирование активного маршрута.
- **Инструменты пассажира:**
  - Отмена бронирования в любое время;
  - Оставление отзыва и оценки (1–5 звезд) водителю после завершения поездки.

### 4. 👤 Личный профиль (`ProfileScreen`)
- **Личные данные:** редактирование имени, подтвержденного номера телефона и Telegram-username (`PATCH /api/auth/me`).
- **Аватар пользователя:** загрузка фото профиля с предварительной проверкой размера и формата на клиенте.
- **Гараж автомобилей:**
  - Просмотр добавленных машин;
  - Форма добавления авто с указанием вместимости (`seats`, от 1 до 8 мест);
  - Модальное окно редактирования авто.
- **Настройки:** переключение темы оформления (светлая / темная).

### 5. 🛡 Панель администратора (`AdminScreen`)
- Доступна по роуту `/admin` или хэшу `#admin`.
- Метрики сервиса, список пользователей, блокировка/разблокировка аккаунтов.

## 🗺 Интеграция с Яндекс Картами (API 2.1)

Интеграция реализована на уровне специализированных хуков и компонентов:

```text
frontend/src/
├── components/
│   └── RouteMap.tsx             # Интерактивная карта маршрута поездки
├── hooks/
│   ├── useAddressSuggest.ts     # Автодополнение адресов (ymaps.suggest + API)
│   ├── useRouteMap.ts           # Управление инстансом YMaps2Map, polyline и метками
│   └── useRideForm.ts           # Управление состоянием формы и расчетом маршрута
```

1. **Инициализация:** в [index.html](file:///C:/Users/denis/Documents/antigravity/taksi/taksi/frontend/index.html) загружается ядро Яндекс Карт `ymaps`. Хуки проверяют готовность скрипта через `ymaps.ready()`.
2. **Ограничение областью Екатеринбурга:** поиск адресов ограничен жесткими гео-границами Екатеринбурга (`[56.60, 60.20]` – `[57.05, 61.05]`), что исключает выдачу нерелевантных адресов из других регионов.
3. **Отрисовка полилинии:** координаты маршрута преобразуются в объект `ymaps.Polyline` и масштабируются по границам (`map.setBounds(...)`) с отступами по краям для удобного просмотра на мобильных экранах.

## 📁 Структура исходного кода

```text
frontend/
├── public/                      # Статические файлы, манифест, иконки
├── src/
│   ├── api/                     # Модуль API-запросов к серверу Express
│   ├── components/              # Переиспользуемые UI-компоненты (RouteMap, RideCard, BottomNav...)
│   ├── hooks/                   # Пользовательские хуки (useRouteMap, useAddressSuggest, useRideForm...)
│   ├── screens/                 # Основные экраны приложения (FindRides, OfferRide, MyTrips...)
│   ├── types/                   # Интерфейсы и TypeScript-типы
│   ├── utils/                   # Вспомогательные утилиты (форматирование дат, NLP-парсер, формулы цен)
│   ├── App.tsx                  # Корневой компонент с маршрутизацией и провайдерами
│   ├── AppContext.tsx           # Глобальное состояние (пользователь, поездки, действия)
│   ├── ThemeModeContext.tsx     # Контекст переключения светлой/темной темы
│   ├── theme.ts                 # Определение цветовых палитр и типографики MUI
│   └── main.tsx                 # Точка входа React
├── index.html                   # HTML-шаблон с подключением Яндекс Карт API 2.1
├── vite.config.ts               # Конфигурация сборщика Vite
└── package.json                 # Зависимости и скрипты
```
