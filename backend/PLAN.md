# План разработки Бэкенда (Попутка ИИ)

## Этап 1: Базовая инфраструктура (Скелет)
- [ ] Инициализация проекта (package.json).
- [ ] Установка зависимостей (Express, pg, cors, dotenv).
- [ ] Настройка подключения к базе данных PostgreSQL (PostGIS).
- [ ] Базовая структура (routes, controllers, db).

## Этап 2: Базовое "Решение" (CRUD и Авторизация)
- [ ] `POST /api/auth/login` — Авторизация/Регистрация (username, password).
- [ ] `POST /api/rides` — Публикация маршрута водителем.
- [ ] `GET /api/rides` — Базовое получение списка поездок (пока без сложных гео-фильтров).
- [ ] `POST /api/rides/:id/join` — Присоединение пассажира к поездке (создание Match).
- [ ] `POST /api/rides/:id/leave` — Отмена участия пассажира.

## Этап 3: Алгоритмы ядра (PostGIS и Математика)
*Согласно "Решению", ИИ для этого пока не нужен — используем PostGIS и простые алгоритмы.*
- [ ] Внедрение гео-матчинга (PostGIS `ST_DWithin`) в `GET /api/rides`: поиск пересечений маршрутов пассажира и водителя с учетом радиуса и времени.
- [ ] Базовый расчет расстояния поездки (`distanceKm`).
- [ ] Базовое динамическое ценообразование и выявление пиковых часов (`isPeak`) на основе математики и времени.

## Этап 4: AI-фичи (Умный поиск)
*Реализуется только когда готово базовое решение.*
- [ ] Подключение API LLM (например, Gemini/OpenAI).
- [ ] `POST /api/rides/ai-search` — Парсинг естественного языка (например, "завтра с уралмаша") в строгие JSON-параметры для гео-поиска БД.
